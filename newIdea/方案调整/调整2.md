> 当前项目：IP-IQA + Local Quality Branch  
> 当前数据集：AGIQA-3K  
> 当前划分：固定 `splits/seed42.json`  
> 当前输入：512 × 512  
> 当前 GPU：RTX 3090 24GB  
> 当前目标：判断 MS-SCANet-inspired MSDA 模块到底“没有效果”，还是“之前没有训练到位”。

---

# 1. 当前结论

现在已有三条重要结果：

```text
E0  IP-IQA baseline

E1  IP-IQA + Weighted Local
    已验证有提升

E3  IP-IQA + MSDA + Weighted Local
    与 E1 基本持平 / 微降
```

同一 batch=32、同一 seed42、同一 20 epoch 条件下：

```text
E1 Weighted Local:
qual SROCC ≈ 0.8179

E3 MSDA:
qual SROCC ≈ 0.8172
```

差距只有约：

```text
-0.0007
```

所以当前不能直接判断：

```text
“MSDA 模块有害”
```

更准确的判断是：

```text
“当前训练方式下，MSDA 没有表现出额外增益。”
```

# 2. 为什么当前 E3 可能没有真正训练起来

现在 E3 新增了大量随机初始化层：

```text
Fine ChannelBlock
Coarse ChannelBlock

Fine SpatialBlock
Coarse SpatialBlock

CrossBranchAttention

Scale Fusion Conv

Refine Gate
```

但是它们和已经预训练好的 CLIP / IP-IQA 主干基本用了相同：

```text
lr = 1e-5
```

当前训练：

```text
batch_size = 32
train images ≈ 2380

每 epoch:
约 75 steps

20 epoch:
约 1500 optimizer steps
```

对 CLIP fine-tuning 来说：

```text
1e-5
```

是合理的。

但对于一整套：

```text
random initialized attention blocks
```

来说：

```text
1e-5 + 1500 steps
```

太保守。

---

# 3. 另一个问题：MSDA 被双重 gate 压制

当前 MSDA 内部：

```python
r = sigmoid(refine_gate_logit)

refined = f0 + r * delta
```

初始化：

```text
refine_gate_logit = -2
r ≈ 0.119
```

外层 Local Fusion：

```python
g = sigmoid(local_gate_logit)

q_final = (1-g) * q_base + g * q_local
```

也是：

```text
local_gate_init = -2
g ≈ 0.119
```

于是 MSDA 新 feature 的初始影响非常弱：

```text
MSDA
 ↓
内部 gate 压一次
 ↓
q_local
 ↓
外层 gate 再压一次
 ↓
Final Quality
```

因此当前 E3 很可能属于：

```text
模块被接进去了
但没有获得足够的学习强度
```

而不是：

```text
模块已经充分训练后被证明无效
```

---

# 4. 调整2的核心原则

这次不再乱改结构。

只解决三个问题：

```text
1. E3 不再从零训练 Local Branch
2. 新 MSDA 模块使用更高学习率
3. MSDA 内部 gate 放开一些
```

同时：

```text
外层 q_base / q_local gate 继续保守
```

保证不会一开始破坏 IP-IQA。

# 6. 第一项调整：用 E1 checkpoint 初始化 E3

这是最重要的一步。

当前 E1 已经验证：

```text
Projection
+
Patch Score Head
+
Patch Weight Head
+
IP-IQA Backbone
```

能够工作。

所以 E3 不应该把这些东西全部重新随机初始化。

正确思路：

```text
先加载 E1 checkpoint

然后保留：

IP-IQA backbone
IP-IQA original head
projection
patch score head
patch weight head
outer local gate

再新增并随机初始化：

ChannelBlock
SpatialBlock
CrossBranchAttention
Scale Fusion
refine gate
```

也就是说：

```text
E3-v2
=
一个已经训练好的 E1
+
一个新的 MSDA refinement
```

而不是：

```text
E3
=
整个 Local Branch 从头重新学
```



然后打印：

```python

```

确认缺失的只应该主要是：

```text

```

如果出现：

```text
IP-IQA backbone
score_head
weight_head
```

也 missing，

说明命名没有对上，需要修。






# 10. 参数分组建议

可以在：

```text
ipiqa/models/ipiqa.py
```

或者 trainer 构建 optimizer 的位置处理。

逻辑：

```python
backbone_params = []
local_old_params = []
msda_new_params = []
gate_params = []
```

按参数名分：

```python
for name, p in model.named_parameters():

    if not p.requires_grad:
        continue

    if "refine_gate_logit" in name:
        gate_params.append(p)

    elif "local_gate_logit" in name:
        gate_params.append(p)

    elif (
        "fine_channel" in name
        or "coarse_channel" in name
        or "fine_spatial" in name
        or "coarse_spatial" in name
        or ".cross." in name
        or ".fuse." in name
    ):
        msda_new_params.append(p)

    elif (
        "local_fusion" in name
        and (
            "proj" in name
            or "score_head" in name
            or "weight_head" in name
        )
    ):
        local_old_params.append(p)

    else:
        backbone_params.append(p)
```

optimizer：

```python
optimizer = AdamW([
    {
        "params": backbone_params,
        "lr": 1e-5,
    },
    {
        "params": local_old_params,
        "lr": 3e-5,
    },
    {
        "params": msda_new_params,
        "lr": 1e-4,
    },
    {
        "params": gate_params,
        "lr": 1e-4,
    },
])
```

# 11. 第三项调整：MSDA 内部 gate 从 -2 改为 -1

原来：

```text
ms_refine_gate_init = -2
```

改为：

```text
ms_refine_gate_init = -1
```

则：

```text
sigmoid(-1)
≈ 0.269
```

意味着：

```text
refined
=
f0
+
0.269 × delta
```

初始阶段 MSDA 会明显参与 feature refinement。

但是仍然是 residual：

```text
f0 保留
+
新增 feature 小幅叠加
```

所以还不算激进。

---

# 12. 外层 Local Gate 继续保持 -2

这个不要一起调大。

继续：

```text
local_gate_init = -2
```

即：

```text
g ≈ 0.119
```

原因：

外层 gate 是保护 IP-IQA baseline 的最后保险。

因此形成：

```text
MSDA 内部：
稍微积极一点

Final Fusion：
仍然保守
```

这是本轮最合理的组合。

---

# 13. 不推荐的设置

不要：

```text
refine gate = 0
outer gate = 0
```

因为：

```text
sigmoid(0)=0.5
```

两个地方都太激进。

也不要：

```text
refine gate = -4
```

因为：

```text
sigmoid(-4) ≈ 0.018
```

MSDA 又几乎学不到。

推荐：

```text
refine gate:
-1

outer gate:
-2
```

# 22. Gate 的判读

如果最终：

```text
refine gate:
0.27 → 0.40
```

说明：

```text
模型主动增强 MSDA 信息
```

如果：

```text
0.27 → 0.05
```

说明：

```text
模型主动压制 MSDA
```

这时即使训练充分：

```text
MSDA 很可能确实不适配
```

如果 gate 基本：

```text
0.27 → 0.27
```

说明：

```text
gate 几乎没学
```

需要再检查：

```text
gradient
optimizer param group
```

```python
for name, p in model.named_parameters():

    if "fine_spatial" in name:

        if p.grad is not None:

            print(
                name,
                p.grad.abs().mean().item()
```

检查：

```text

Spatial
Cross
Fuse
Refine Gate
```

有没有梯度。

如果：

```text

```

那是代码连接问题。

如果：

```text
grad 非零但极小
```

则可能是 gate / lr 抑制。

# 24. 最终判定标准

这一次跑完以后直接止损。

以：

```text
E1 Weighted Local bs32
```

作为真正 baseline。

假设：

```text
E1 ≈ 0.818 SROCC
```

### 情况 A：明显提升

如果：

```text
E3-v2 ≥ E1 + 0.003
```

即大约：

```text
≥ 0.821
```

并且：

```text
PLCC / KROCC 不下降
```

结论：

```text
保留 MSDA
```

继续做消融。

---

### 情况 B：基本持平

如果：

```text
|E3-v2 - E1| < 0.002
```

例如：

```text
E1    0.818
E3-v2 0.819
```

结论：

```text
MSDA 没有足够价值
```

因为：

```text
复杂度明显增加
但性能几乎没变
```

直接换模块。

---

### 情况 C：明显下降

如果：

```text
E3-v2 < E1 - 0.003
```

结论：

```text
MSDA 与当前 IP-IQA Local Branch 不适配
```

直接淘汰。

# 26. 如果调整2失败，下一步怎么换

保留：

```text
IP-IQA
+
Weighted Local
```

因为这个已经验证有效。

只替换：

```text
MSDA refinement
```

下一模块筛选原则：

```text
1. 不能再是大块 self-attention 堆叠

2. 最好是 feature enhancement
   而不是再加一套 Transformer

3. 输入接口必须能接：
   [B,2048,16,16]
   或 projected [B,256,16,16]

4. 不能新增 backbone

5. 参数量控制在 0.1M ~ 2M 左右

6. 最好来自 2024~2026 IQA / AGIQA
```

优先考虑：

```text
局部卷积增强

spatial-channel modulation

frequency-aware lightweight block

deformable / adaptive local aggregation

multi-level feature modulation
```

而不是继续：

```text
Self-Attention
+
Cross-Attention
+
Transformer
```

因为当前两次 attention 类尝试都没有给出明确正增益。
