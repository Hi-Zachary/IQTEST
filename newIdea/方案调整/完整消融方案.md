# 完整消融实验方案（去除 Cross-Branch Attention 版）

> 最终目标：把当前方法收敛成 **3 个清楚、可解释、可逐项消融的创新点**，避免结构过度堆叠。
>
> 最终基础框架仍为 **IP-IQA**，但 **Cross-Branch Attention 从最终模型中移除**。  
> 我们只保留：
>
> 1. 多尺度局部质量表征；
> 2. 空间—通道双注意力局部增强；
> 3. 区域重要性感知的 Patch 加权质量聚合。
>
> 对应只需要 **4 行主消融实验**：
>
> ```text
> IP-IQA
> ↓
> + Multi-Scale
> ↓
> + Dual Attention
> ↓
> + Patch Weight
> =
> Full Ours
> ```

---

# 1. 最终方法结构

去掉 Cross-Branch Attention 后，最终局部分支简化为：

```text
Image + Prompt
      │
      ├───────────────────────────────┐
      ↓                               ↓
  CLIP RN50                       CLIP Text
      │                               │
      ↓                               │
Spatial Feature F                     │
[B, 2048, H, W]                       │
      │                               │
      ├──── Original IP-IQA ──────────┘
      │              ↓
      │           q_base
      │
      └──── Our Local Quality Branch
                     ↓
               1×1 Projection
                2048 → 256
                     ↓
              Multi-Scale Split
                /           \
               /             \
        Fine Feature       Coarse Feature
          16×16               8×8
            ↓                  ↓
      Channel Attention   Channel Attention
            ↓                  ↓
      Spatial Attention   Spatial Attention
               \             /
                \           /
                 ↓         ↓
               Resize + Concat
                     ↓
                  1×1 Fuse
                     ↓
             Residual Refinement
                     ↓
              Patch Score Head
                     +
              Patch Weight Head
                     ↓
          Importance-Aware Aggregation
                     ↓
                  q_local
                     │
             q_base + q_local
                     ↓
                Gated Fusion
                     ↓
               Final Quality
```

这里明确：

```text
不再存在：
Fine ↔ Coarse Cross-Branch Attention
```

Fine 与 Coarse 只在最后通过：

```text
coarse upsample
+
fine feature
+
concat
+
1×1 convolution
```

完成自然的多尺度融合。

---

# 2. 为什么删掉 Cross-Branch Attention

当前代码中的 Cross-Branch Attention 是：

```text
Fine queries Coarse
+
Coarse queries Fine
```

属于 MSDA 内部额外的双向跨尺度注意力。

删除它之后，仍然保留了 MS-SCANet-inspired 设计最容易解释的核心：

```text
Multi-Scale
+
Channel Attention
+
Spatial Attention
```

因此不会破坏整个方法故事。

同时可以减少：

```text
2 个 MultiheadAttention

2 个 LayerNorm

Fine↔Coarse 双向 cross-attention
```

最终方法更适合本科大创：

```text
结构更轻
叙事更清楚
创新点更容易分成 3 个
消融实验更少
```

注意：

> 删除 Cross-Branch 后最终性能是否完全不变，仍需以实际训练结果为准。  
> 本方案的目的不是保证删掉后一定不掉点，而是在尽量保留核心思想的前提下做结构减法。

# 3. 最终三个创新点

---

## 创新点 1：多尺度局部质量表征

### 中文名称

**多尺度局部质量表征模块**

### 英文名称

**Multi-Scale Local Quality Representation**

### 核心结构

从 IP-IQA 的 CLIP RN50 空间特征：

```text
F ∈ R^(B×2048×16×16)
```

先投影：

```text
2048
↓
256
```

得到：

```text
F0 ∈ R^(B×256×16×16)
```

再建立两个尺度：

```text
Fine:
16×16

Coarse:
AvgPool2d(Fine)
→ 8×8
```

即：

```text
F_fine = F0

F_coarse = AvgPool2d(F0, 2)
```

### 解决的问题

AI 生成图像中的质量问题不一定只存在于一个空间尺度：

```text
小尺度：
纹理异常
边缘错误
局部伪影
细节破碎

较大尺度：
区域结构不合理
局部布局异常
较大范围的不一致
```

所以单一空间特征表示可能不足。

### 创新点表述建议

> 针对 AI 生成图像中质量退化具有不同空间尺度的问题，在 IP-IQA 的 CLIP 空间特征基础上构建细粒度与粗粒度双尺度局部表示，使模型能够同时感知细节级与区域级生成缺陷。

---

# 4. 创新点 2：空间—通道双注意力局部增强

### 中文名称

**空间—通道双注意力局部质量增强模块**

### 英文名称

**Spatial-Channel Dual-Attention Local Refinement**

### 核心结构

Fine 和 Coarse 两个尺度分别执行：

```text
Feature
↓
Channel Attention
↓
Spatial Attention
↓
Refined Feature
```

即：

```text
Fine:
ChannelBlock
→
SpatialBlock

Coarse:
ChannelBlock
→
SpatialBlock
```

不再使用：

```text
Cross-Branch Attention
```

两个尺度处理完成后：

```text
Coarse
↓
Bilinear Upsample
↓
与 Fine Concat
↓
1×1 Conv Fusion
```

### Channel Attention 作用

强调：

```text
哪些特征通道
更具有质量判别作用
```

例如与：

```text
纹理
结构
边缘
伪影
```

相关的特征通道。

### Spatial Attention 作用

强调：

```text
哪些空间位置
更值得关注
```

用于增强局部质量敏感区域。

### 创新点表述建议

> 在多尺度局部表示基础上，引入空间—通道双注意力机制，从特征通道和空间位置两个维度增强质量敏感信息，使模型更加关注与生成伪影和局部结构异常相关的特征响应。

---

# 5. 创新点 3：区域重要性感知的 Patch 加权质量聚合

### 中文名称

**区域重要性感知的局部质量聚合模块**

### 英文名称

**Importance-Aware Patch Quality Aggregation**

### 核心结构

增强后的局部特征：

```text
[B, 256, H, W]
```

展开：

```text
[B, N, 256]
```

对每个 patch 同时预测：

```text
Patch Quality Score
s_i

+

Patch Importance Weight
w_i
```

最终：

```text
q_local
=
Σ(w_i × s_i)
/
Σ(w_i)
```

而不是简单：

```text
mean(s_i)
```

### 解决的问题

不同图像区域对整体主观质量的影响并不一样。

例如：

```text
主体面部异常
```

通常比：

```text
背景中一个很小的纹理问题
```

对整体主观质量影响更大。

因此让模型学习：

```text
每个 patch 的质量
+
每个 patch 的重要程度
```

比对全部 patch 等权平均更合理。

### 与 IP-IQA 的融合

得到：

```text
q_local
```

后与 IP-IQA：

```text
q_base
```

进行门控融合：

```text
q_final
=
(1-g) q_base
+
g q_local
```

其中：

```text
g = sigmoid(local_gate_logit)
```

注意：

> **Gated Fusion 不再单独算第四个创新点。**
>
> 它作为局部分支接入 IP-IQA 的工程融合方式，归入创新点 3 的整体质量预测过程。

### 创新点表述建议

> 针对不同局部区域对整体图像质量贡献不一致的问题，设计区域重要性感知的 patch-wise 质量聚合机制，同时预测局部质量分数和重要性权重，并将得到的局部质量估计与 IP-IQA 的全局跨模态质量预测进行自适应融合。

```text

→

```

这样三个创新点天然形成一条完整 pipeline。

# 22. aggregation 实现

建议：

```python
patch_score = self.score_head(x)

if self.aggregation == "weighted":
    patch_weight = self.weight_head(x)

    q_local = (
        patch_score * patch_weight
    ).sum(dim=1) / (
        patch_weight.sum(dim=1) + 1e-6
    )

else:
    q_local = patch_score.mean(dim=1)
```

这样：

```text
mean
vs
weighted
```

是完全公平的。

# 23. A1 的 Multi-Scale 怎么实现

A1 不能把整个 Refiner 都关闭。

它仍然要有：

```text
Projection
↓
Fine
+
Coarse
↓
Resize
+
Concat
↓
1×1 Fuse
```

只是跳过：

```text
ChannelBlock
SpatialBlock
```

伪代码：

```python
fine_map = f0

coarse_map = F.avg_pool2d(
    f0,
    kernel_size=2
)

coarse_up = F.interpolate(
    coarse_map,
    size=fine_map.shape[-2:],
    mode="bilinear",
    align_corners=False,
)

delta = self.fuse(
    torch.cat(
        [fine_map, coarse_up],
        dim=1
    )
)

x = f0 + r * delta
```

这就是真正的：

```text
Multi-Scale only
```

# 32. 为什么消融可以用统一 30 epoch

正式主结果和消融的目的不同。

正式主结果：

```text
目标：
尽可能得到充分收敛的最终性能

→ 可以 100 epoch
```

消融：

```text
目标：
公平比较不同模块的相对作用

→ 统一 30 epoch 即可
```

因此推荐：

```text
Main Experiment:
Full Ours
100 epoch total

Ablation:
A0/A1/A2/A3
统一 30 epoch
```

不要把：

```text
30 epoch ablation
```

和：

```text
100 epoch final
```

混在同一张数值表里。

中文：

> **在 AGIQA-3K 固定划分及统一 30-epoch 训练协议下的模块消融实验。**

# 34. 学习率怎么保证公平

为了消融的公平性：

```text
A1
A2
A3
```

新增局部分支采用相同的优化原则。

推荐：

```text
IP-IQA pretrained part:
1e-5

Local projection / score head:
3e-5

Dual Attention blocks:
1e-4

Patch Weight head:
1e-4

Gates:
1e-4
```

不存在的模块自然没有对应参数组。

例如 A1：

```text
没有 Dual Attention
没有 Weight Head

所以只有：
backbone
local projection/score
gate
```

# 35. 是否要 warm start

## 消融实验

建议：

```text
不要 A1 → A2 → A3 依次 warm start
```

因为这样会产生：

```text
A3 实际训练时间比 A2 长
A2 又比 A1 长
```

不好解释。

最好：

```text
A0/A1/A2/A3
都从同一个基础初始化出发
```

例如：

```text
同一个 CLIP RN50 pretrained checkpoint
+
相同随机 seed
```

这样模块差异更干净。

这一条与消融不冲突。

正式最终模型为了追求性能，可以继续采用：

```text
Weighted / Local warm-up
→
Full
```

或者后续确定的长训练策略。

但是：

```text
Ablation Protocol
```

和：

```text
Final Training Protocol
```

要在文档里分开写。

# 37. 消融 checkpoint 选择

因为三个创新点都主要服务：

```text
Perceptual Quality
```

所以消融不要再用：

```text
Quality + Alignment joint aggregate
```

选 checkpoint。

推荐统一：

```text
best_quality
=
argmax(
    SRCC_quality
    +
    PLCC_quality
)
```

最终每组报告：

```text
Quality SRCC
Quality PLCC
Quality KROCC
```

# 38. 为什么只看 Quality 主表

我们新增的：

```text
Multi-Scale
Dual Attention
Patch Weight
```

全部作用在：

```text
quality local branch
```

而 alignment output 在当前模型中：

```text
仍沿用 IP-IQA alignment prediction
```

所以主消融表理应聚焦：

```text
Perceptual Quality
```

Alignment 可以另外记录，但不需要作为创新点消融的核心。

# 41. Dual Attention 为什么不拆成两个消融

虽然 Dual Attention 内部包括：

```text
Channel Attention
+
Spatial Attention
```

但我们将它整体定义为创新点 2：

```text
Spatial-Channel Dual Attention
```

因此消融只验证：

```text
有 Dual Attention
vs
没有 Dual Attention
```

不再单独问：

```text
Channel 到底贡献多少
Spatial 到底贡献多少
```

这样可以减少两组实验。

# 43. 如果某个中间创新点没有涨怎么办

例如：

```text
A0 = 0.820

A1 = 0.821

A2 = 0.819

A3 = 0.835
```

不要为了表好看去改数字。

首先看：

```text
Full 是否优于 baseline
```

然后分析：

```text
单模块可能需要与后续模块协同
```

不过如果：

```text
A2 明确持续低于 A1
```

那最终报告中应谨慎声称 Dual Attention 的独立贡献。

所以消融的意义就是：

```text
让贡献表述跟真实结果匹配
```

而不是提前规定每一步必须单调上涨。
